## 2. Collation Standardization & Search Semantics (M8.1 Fixes)

- **Standardized Collation:** `utf8mb4_0900_ai_ci` across all 28 tables in the baseline migration (`apps/api/prisma/migrations/20261106120000_init_mysql/migration.sql`).
- **Engine Compatibility:** Evaluated against MySQL 8.0 default configuration. In MySQL 8.0, `utf8mb4_0900_ai_ci` is the server default, offering modern Unicode 9.0 UCA weights, accent-insensitivity (`ai`), and case-insensitivity (`ci`).
- **Application Normalization:** Audited and enforced uppercase normalization on identifiers (`employeeId`, `plateNumber`, `licenseNumber`, `code`) and lowercase on `email` at application boundaries to guarantee consistent formatting across caches, logs, and database rows.
- **MySQL Column Constraint Fix:** Removed illegal `DEFAULT ''` on `TEXT` column `SupportMessage.content` for MySQL 8.0 compatibility (error 1101).

## 5. Detailed Test Suite Coverage

### A. Fresh Database Migration Verification (Phase 4.A)
- Introspects `information_schema.TABLES` to verify existence of all 28 application tables.
- Verifies baseline record in `_prisma_migrations` (`20261106120000_init_mysql`, `applied_steps_count = 1`, `rolled_back_at IS NULL`).
- Confirms table-level collation `utf8mb4_0900_ai_ci`.

### B. Foreign Key Behavior (Phase 4.B)
- **Cascade Deletion:** User deletion cascades to `Driver`. Complaint deletion cascades to `ComplaintAttachment` and `ComplaintUpdate`.
- **Set Null Deletion:** Driver deletion sets `Vehicle.driverId` to `NULL` without deleting the vehicle.
- **Constraint Rejection:** Inserting child records (`Driver`) with non-existent parent foreign keys is rejected by MySQL InnoDB (`P2003` / errno 1452).

### C. Collation Behavior (Phase 4.C)
- **Case-Insensitive Equality & Search:** Verifies `'RAHUL.KUMAR@EXAMPLE.COM'` matches `'rahul.kumar@example.com'`, and `'ahu'` matches `'Rahul'`.
- **Accent-Insensitive Equality:** Verifies `'Citroen'` matches `'Citroën'` under `utf8mb4_0900_ai_ci`.
- **Case-Variant Collision Rejection:** Verifies unique index on `employeeId` and `email` rejects duplicate values differing only by case.

### D. Idempotency Key Behavior (Phase 4.D)
- Verifies `Complaint` composite unique constraint `@@unique([driverId, idempotencyKey])`.
- Confirms duplicate rejection for the same driver.
- Confirms key acceptance when used by different drivers.
- Confirms multiple `NULL` idempotency keys are permitted per driver in accordance with SQL and MySQL unique index semantics.
